# Card Component

Reusable card container component for TaskFlow.

## Usage

```javascript
import { Card } from './Card.js';

const card = new Card({
  title: 'Card Title',
  subtitle: 'Card Subtitle',
  shadow: 'md'
});
```

## Props

- `title`: Card title
- `subtitle`: Card subtitle
- `shadow`: Shadow intensity (sm, md, lg)
